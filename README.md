# ppt-html-examples

[ppt-html 스킬](https://github.com/Krocean/PPHTML-BD)로 만든 발표 자료 예시 모음입니다. 덱 18개가 zip 하나에 들어 있습니다.

## 내려받기

[ppt-html-examples-v1.zip](https://github.com/Krocean/ppt-html-examples/releases/download/v1/ppt-html-examples-v1.zip) (228MB)

다른 판은 [Releases](https://github.com/Krocean/ppt-html-examples/releases)에 있습니다.

## 들어 있는 것

폴더 하나가 덱 하나이고, 폴더마다 다음 파일이 있습니다.

- `이름.pptm`: 발표용 PowerPoint 파일. 슬라이드 쇼를 시작하면 슬라이드가 그 자리에서 움직이는 웹 화면으로 바뀝니다. Windows용 PowerPoint 데스크톱 앱과 매크로 허용이 필요합니다.
- `이름.html`: 같은 내용을 웹 브라우저로 보는 파일. 더블클릭하면 바로 열리고 Mac·휴대폰에서도 됩니다. ←/→ 키로 넘깁니다.
- `design.md`: 그 덱의 디자인 규칙(색, 글꼴, 간격, 움직임). 있는 덱만 들어 있습니다.

덱 목록: SpaceX, Claude, OpenAI Astra, Google Neon, McKinsey, Apple, Tesla, Nike, Netflix, Stripe, NASA, Airbnb, 삼성전자, 현대자동차, 토스, 카카오, 배달의민족, HYBE

## PowerPoint 파일 여는 방법

인터넷으로 받은 파일은 Windows가 매크로를 막아 둡니다. 이때는 슬라이드가 정지 그림으로만 보입니다.

1. zip을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 눌러 [속성]을 엽니다.
2. 아래쪽 '보안' 항목의 [차단 해제]에 체크하고 [확인]을 누른 뒤 압축을 풉니다. 이미 풀었다면 `.pptm` 파일마다 같은 방법으로 [차단 해제]를 합니다.
3. `.pptm`을 열고 노란색 줄이 보이면 [콘텐츠 사용]을 누릅니다.
4. 슬라이드 쇼를 시작합니다(F5).

회사 보안 정책으로 매크로가 전면 차단된 PC에서는 `.html` 파일을 쓰세요. Mac·웹·모바일용 PowerPoint에서도 정지 그림으로만 보이므로 `.html`을 쓰면 됩니다.
